Jak podłączyć aplikację?

Nachtwache jest w 100% kompatybilne z oficjalnymi bibliotekami Sentry. Wystarczy podmienić URL w dsn.

1. Twój DSN Nachtwache

http://public@localhost:8080/1

2. JavaScript / TypeScript / React / Next.js

import * as Sentry from "@sentry/browser";

Sentry.init({
  dsn: "http://public@localhost:8080/1",
  tracesSampleRate: 1.0,
});

3. Node.js / Express / NestJS

import * as Sentry from "@sentry/node";

Sentry.init({
  dsn: "http://public@localhost:8080/1",
});

4. Python / Django / FastAPI / Flask

import sentry_sdk

sentry_sdk.init(
    dsn="http://public@localhost:8080/1",
    traces_sample_rate=1.0,
)

Konfiguracja silnika AI

Wybierz model, który będzie automatycznie diagnozował błędy i generował łatki (patche).
